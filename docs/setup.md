# Development Setup

## Prerequisites

| Tool | Version | Purpose |
|---|---|---|
| PHP | 8.3+ | Laravel backend |
| Composer | 2.x | PHP dependency manager |
| Node.js | 18+ | Frontend build |
| npm | 9+ | JS dependency manager |
| MySQL | 8 (dev) | Production-like database |
| SQLite | 3.x | Test database (in-memory) |

## Quick Start

```bash
# Clone and setup backend (installs deps, generates key, runs migrations, seeds, builds assets)
cd api
composer setup

# Start backend (Laravel + Vite HMR on port 8000)
composer dev

# In a separate terminal — start frontend (React SPA)
cd frontend
npm install
npm run dev
```

## Default Admin Account

- **Email:** `admin@test.com`
- **Password:** `password`

## Environment Configuration

Backend env is at `api/.env` (copied from `.env.example` by `composer setup`).

Key values:

```env
APP_URL=http://localhost:8000
DB_CONNECTION=sqlite          # default for dev
JWT_SECRET=<auto-generated>   # set by key:generate
```

For MySQL instead of SQLite:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=test_portal
DB_USERNAME=root
DB_PASSWORD=
```

## Dev Servers

| Command | What it runs | URL |
|---|---|---|
| `cd api && composer dev` | Laravel + queue + Vite (HMR) | `http://127.0.0.1:8000` |
| `cd frontend && npm run dev` | Vite React SPA | `http://127.0.0.1:5173` |

The frontend Vite dev server proxies `/api` requests to `http://127.0.0.1:8000` (the Laravel backend). Both servers must be running for the frontend to work.

## Running Tests

Tests use **SQLite in-memory** (configured in `api/phpunit.xml`), so no MySQL instance is needed.

```bash
cd api

# Run all tests
php artisan test --compact

# Run a single test by name
php artisan test --compact --filter=testName

# Clear config cache + run tests (recommended after config changes)
composer test
```

```bash
cd api && npm run build         # vite build
```

## Troubleshooting

### Frontend can't reach API

Both servers must be running. The frontend proxies `/api` to `http://127.0.0.1:8000`. If the backend isn't running, you'll see network errors.

### JWT token errors / 401 loops

Ensure `JWT_SECRET` is set in `api/.env`. Run `php artisan key:generate` to regenerate if missing.

### Migration errors

```bash
cd api
php artisan migrate:fresh --seed    # reset database and re-seed
```

### Vite HMR not picking up changes

Restart the dev server. If issues persist, clear the cache:

```bash
cd api && rm -rf bootstrap/cache/*
```

### Tests failing with database errors

Tests use SQLite in-memory regardless of your `.env` DB config. If tests fail, check `api/phpunit.xml` — the `DB_CONNECTION=sqlite` and `DB_DATABASE=:memory:` overrides must be present.
